# راهنمای نصب دیده‌بان نسخه 2.4

## تغییرات
- قطعه‌بندی سمت مرورگر روی 3000 نویسه برای کاهش احتمال خروجی JSON بریده‌شده.
- حداکثر 4096 توکن خروجی برای هر قطعه، همراه با خروجی JSON ساختاریافته.
- مدل اصلی: مقدار فعلی GEMINI_MODEL یعنی gemini-3.5-flash-lite.
- مدل پشتیبان پیشنهادی: gemini-3.6-flash.
- حداکثر دو فراخوانی مدل در هر درخواست Edge Function و سقف زمانی واقعی 70 ثانیه با 8 ثانیه رزرو برای ذخیره پایگاه داده.
- تشخیص صریح finishReason=MAX_TOKENS و ثبت بخش ناموفق برای تلاش مجدد.
- حفظ ساختار JSON موردنیاز بخش تأیید و نگاشت فعالیت‌ها به دفتر کارکرد.

## نصب
1. در Supabase > Edge Functions > didehban-ai-documents، محتوای index.ts را کامل جایگزین و Deploy updates کنید.
2. در Supabase > Edge Functions > Secrets، مقدار GEMINI_FALLBACK_MODELS را برابر gemini-3.6-flash قرار دهید.
3. GEMINI_MODEL را برابر gemini-3.5-flash-lite نگه دارید. کلیدهای API را تغییر ندهید.
4. فایل index.html نسخه 2.4 را در ریشه مخزن GitHub Pages جایگزین کنید و Commit کنید.
5. سایت را با Ctrl+Shift+R باز کنید و همان فایل را دوباره تحلیل کنید.

## یادآوری
- این نسخه از نظر نحوی بررسی می‌شود، اما نتیجه اجرای واقعی Gemini فقط پس از Deploy قابل تأیید است.
- نسخه 2.4 کلید idempotency جدید دارد؛ اسناد نسخه‌های قبلی حذف یا تأیید خودکار نمی‌شوند.
- دکمه تأیید و ذخیره فقط پس از بررسی انسانی خروجی استفاده شود.
